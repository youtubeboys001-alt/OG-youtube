# Rewritten Image Prompts (Names Removed → Full Physical Descriptions)

All 175 prompts below have been rewritten so that **no character name is ever used anywhere** — not as the subject of an image, and not in any on-screen text, spoken dialogue, title-card label, or logo lettering. Wherever a character appears, the name is replaced with that character's complete, detailed physical description (age range, gender, height and body type, skin tone, hair style and color, facial features, distinctive accessories, expression, posture, and wardrobe). Prompts that need no character are written as pure scene/object/environment descriptions. All composition, lighting, mood, camera, realism level, and artistic style are preserved unchanged.

> **Note:** Names have also been removed from all on-screen text, spoken dialogue, title-card labels, and logo lettering, so this document contains no character names at all. (Academic citations of real published researchers in the source material are left intact, as they are factual references rather than characters.)
